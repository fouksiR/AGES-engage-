# Fertility Preservation in Endometriosis - Clinical Tutorial

An interactive, educational tutorial for AGES members, GPs, and specialists on when to refer patients for fertility preservation consultation.

## Overview

This tutorial provides evidence-based guidance for identifying endometriosis patients who may benefit from fertility preservation, based on leading research in the field.

## Features

- **4-Stage Interactive Tutorial**
  - Stage 1: When to Refer for Fertility Preservation
  - Stage 2: Treatment Options & Expected Outcomes
  - Stage 3: Key Takeaways Summary
  - Stage 4: Public vs Private Funding & Specialist Contact

- **Modern UI/UX**
  - Video background with frosted glass cards
  - Hover animations and interactive elements
  - Responsive design for all devices
  - Floating WhatsApp contact widget

- **Evidence-Based Content**
  - References from La Marca, Somigliana, ASRM, and other leading researchers
  - AMH normogram for ovarian reserve assessment
  - Public funding criteria for Australia

## Deployment

Simply upload all files to your web hosting. The tutorial will be accessible via `index.html`.

### GitHub Pages Deployment

1. Upload all files to a GitHub repository
2. Enable GitHub Pages in repository settings
3. Select the main branch as source
4. Your tutorial will be live at: `https://[username].github.io/[repository-name]/`
